# 🌐 Formularios Redes Sociales

Colección de **formularios clonados** de redes sociales populares, creados con **HTML5** y **CSS3**, aplicando **Flexbox** y **Grid** para maquetación responsiva.  
El objetivo de este proyecto es practicar **diseño de interfaces modernas** y la correcta **estructuración semántica** de formularios.  

---

## 🚀 Formularios incluidos
- 📸 **Instagram** – Formulario de portada/login.  
- 📧 **Google** – Formulario de inicio de sesión con cuenta de Google.  
- 👍 **Facebook** – Formulario de login clásico de Facebook.  

---

## 🛠️ Tecnologías utilizadas
- HTML5  
- CSS3  
- Flexbox  
- CSS Grid
